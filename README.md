# STM32 Learning & Embedded Systems

This repository documents my learning journey with **STM32 microcontrollers**, **Embedded C**, and low-level ARM-based embedded programming.

The repository contains code experiments, peripheral implementations, register-level programming, measurements, and notes developed while learning STM32 development.

---

## 📌 About

The primary focus of this repository is understanding how STM32 microcontrollers work at the hardware and register level rather than relying entirely on high-level libraries.

Topics explored include:

- Embedded C
- STM32F4 microcontrollers
- GPIO programming
- RCC and peripheral clock configuration
- Clock configuration
- HSE and HSI
- Memory-mapped registers
- `volatile` and hardware registers
- Register-level programming
- Peripheral initialization
- ARM Cortex-M concepts
- STM32 development using STM32CubeIDE
- Debugging and hardware experiments
